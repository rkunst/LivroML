# Dados

O piloto do Capítulo 2 gera dados sintéticos em memória e não utiliza arquivos externos.
Os números são didáticos e não representam medições industriais reais.

Para materiais futuros, registre fonte, versão, licença, data de acesso e procedimento
de obtenção. Prefira instruções de download a redistribuir bases grandes.
Não versione dados privados, credenciais ou materiais sem permissão de redistribuição.
